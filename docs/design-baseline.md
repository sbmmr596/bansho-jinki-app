# デザイン基準（ロック済み）

この文書は **万象神器アプリ** の画面・カード・タイポの固定基準。ステージ／カード／グリッドは変更しない。タイポは視認性改善でラダーを上げた（`--text-scale` 連動）。実装は `src/game/design.ts` と CSS カスタムプロパティ（`:root` / `.game-stage`）に集約する。

## ステージ

| 項目 | 値 | 備考 |
|------|-----|------|
| デザイン解像度 | **1280×720** | `DESIGN_W` / `DESIGN_H`。`.game-stage` の論理サイズ |
| コンテンツ安全インセット | **24px** | 内側の実用領域 **1232×672** |
| safe-area（ノッチ等） | 外側レターボックスのみ | `env(safe-area-inset-*)` は `.game-frame` 側。ステージ自体は常に 1280×720 |

スケールは **contain**（短い辺に合わせる）。`scale = min(availW/1280, availH/720)` で、**上限 1 は付けない**（PC/タブレットでは 1 超の拡大可。例: 1920×1080 → 約 1.5）。ビューポートが 16:9 でないときだけ外側レターボックス（`.game-frame` の暗い余白）。カバー／クロップや縦持ち専用レイアウトはしない。ステージ内レイアウトは上記ピクセルで固定し、端末セーフエリアで縮めない。

## カード

| 項目 | 値 |
|------|-----|
| アスペクト | **2:3**（幅:高さ） |
| マスターアート | **1152×1728** |
| 表示幅ラダー | mini **48** / xs **76** / sm **100** / md **120** / lg **160**（高さは 2:3 で自動） |

### 原寸・原作メモ

- 物理トレーディングカードの一般的な寸法はおおよそ **55×83 mm**（[Wikipedia: Trading card](https://en.wikipedia.org/wiki/Trading_card)）／電撃・最終弾系では **56×83 mm** 表記もあり、いずれも **約 2:3**。
- 神羅万象フロンティア: 公開情報では表示解像度 **≥800×600** 程度まで。Flash ステージの正確なピクセルは不明のため、本アプリは 1280×720 を独自ロックとする。
- 立ち絵（スタンディー）目安: 頭身 **4.5〜5.5** 程度（任意参照。厳密ロックではない）。

## タイポグラフィ（論理 px）

| トークン | サイズ |
|----------|--------|
| caption | **14** |
| body | **16** |
| ui | **18** |
| title | **24** |
| display | **38–46** |

ステージが `transform: scale()` で**縮む**とき、`.game-stage` の `--text-scale`（`--stage-scale` から算出、最大 1.35）が上記トークンをわずかに拡大する。`scale ≥ 1`（PC などでの拡大）では `--text-scale` は 1 のままなので、文字はステージと一緒に大きくなる。電話縦持ちのレターボックスでも UI 文字が極端に潰れないようにするため。レイアウトは 8px グリッドのまま。

画面内の本文・注釈は caption/body/ui に合わせて一段大きい（Tailwind の `text-xs` / `text-sm` / `text-base`、および `text-[Npx]` の小さい指定）。カード面の名前だけは枠に収まるよう +1px に抑える。ボタン・セレクト・入力は論理 44px 以上（`--touch-min`）。

## タッチ・グリッド

| 項目 | 値 |
|------|-----|
| タッチ最小ヒット | **44×44** |
| グリッド基本単位 | **8px**（8 / 16 / 24 / 32） |

## 実装対応

- TypeScript: `src/game/design.ts`
- CSS: `:root` の `--design-*` / `--card-w-*` / `--font-*` / `--touch-min` / `--space-*` など。`.game-stage` は `--design-w` / `--design-h` を参照。
- `GameApp` のステージ寸法は `design.ts` の `DESIGN_W` / `DESIGN_H` を使用。
