## 1. 技の分類（437 / 429 の見出し）

どちらのページも「攻撃対象 × 追加効果」の組み合わせでカードを分類している。

| 大分類 | 中身 |
|---|---|
| 正面攻撃 | 正面の敵を攻撃。TYPE:無/地 特効。必殺技には「相手HPに応じてダメージ変化（割合）」もある |
| 正面攻撃＋状態異常 | 正面攻撃 **さらに** 対象の与ダメージダウン / 被ダメージアップ / 行動を遅らせる / 行動不能 / 補助効果打ち消し / 常時効果打ち消し |
| 正面攻撃＋補助効果 | 正面攻撃 **さらに** 自身の与ダメージアップ / 自身を回復 |
| 連続・貫通・なぎ払い | 正面に連続攻撃 / 貫通（横一列）/ なぎ払い（縦一列）/ なぎ払い＆貫通 |
| ランダム攻撃（＋状態異常／＋補助効果） | 上と同じ追加効果の組み合わせが「ランダムな敵」版でそろっている。ランダム連続・ランダムなぎ払いもある |
| 全体攻撃 | 敵全体を攻撃（＋補助効果打ち消し）、Ｘ字・十字 |
| 敵状態異常（ダメージなし） | 基本技: 正面かランダムの敵1体に 与ダメダウン / 被ダメアップ / 遅らせる / 行動不能。必殺技: **敵全体**に同じもの |
| 味方に補助効果（ダメージなし） | 基本技: ランダムな味方1体に 与ダメアップ / 被ダメダウン / 早める / 回復、味方全体を状態異常から守る。必殺技: **味方全体** |
| 反撃（必殺技のみ） | 瀕死時（HP35%以下）に直接攻撃へ反撃 |
| 常時効果（必殺技枠のみ） | 自身のHP/与ダメ/被ダメ/速アップ（＋状態異常無効） |

つまり原作は **「攻撃方法（正面/ランダム/全体…）」と「追加効果」が別の軸**になっている。
同じ一覧に「攻撃なしの状態異常／補助」も並んでいて、それは基本技なら単体、必殺技なら全体が対象。

## 2. 状態異常・補助効果の仕組み（能力ページ）

- **持続: 「次の攻撃1回分」**。敵味方とも、状態異常や補助によるステータス変化は1回の攻撃で消える。
  - 与ダメージアップ: 次の自分の攻撃1回に乗る。連続攻撃では **1撃目だけ**。反撃で使われても消える。
  - 被ダメージアップ（＝防御ダウン）: 次に受ける攻撃1回で消える。貫通・なぎ払い・全体では範囲内の全員それぞれに効き、全員の分が消える。
  - wiki の定石: 「守るなら味方の防御アップより敵の攻撃ダウン」「攻めるなら敵の防御ダウンより味方の攻撃アップ」（全体攻撃1回で防御側の変化が全部剥がれるため）。攻撃アップと防御ダウンは掛け算で重なる。
- **重ね掛けなし・上書き**: 同じ系統の効果がかかっている相手がいれば、そこへ優先して上書きする。
  「与ダメアップ⇔与ダメダウン」「被ダメアップ⇔被ダメダウン」はお互いに上書きし合う。
- **遅らせる**: ウェイトライン（ATB）上の敵を、ライン全長に対して一定割合だけ後ろへ下げる。右端より後ろへは行かない（持ち越しなし）。
- **早める**: 味方を一定割合だけ前へ進める。左端に届いたらその場で行動する。基本技の場合は、ライン上でいちばん後ろにいる味方が対象。
- **行動不能**: 一定秒数、ウェイトライン上で止まる。止まっている間に早める・遅らせるを受けると、止まったまま前後に動く（重ね掛けできる）。
- **状態異常から守る**: 次に受ける与ダメダウン・被ダメアップ・遅らせる・行動不能を1回だけ防ぐ。
- **打ち消し**: 補助効果（与ダメアップ / 被ダメダウン / 守る）か常時効果を消す。
- 速度の目安: 速100で1ターン約5秒（ターン秒数 ≒ 500 ÷ 速）。

## 3. ガード／ガード不能／クリティカル

- タイプ相性で「強い」側から攻撃するとクリティカル（1.5倍、「少し強い」なら1.2倍）。「弱い」側から攻撃するとガード（0.5倍、「少し弱い」なら0.75倍）。
- 常時効果「TYPE:●の攻撃をガード」は、相性に関係なくそのタイプの攻撃をすべてガードする。
- **ガード不能**: この技はガードされない（相性で強い相手にも、ガード常時効果を持つ相手にも）。攻撃は通常倍率、または相性どおりのクリティカルになる。
  優先順位: ガード不能 ＞ 常時効果ガード ＞ クリティカル。
  原作では「修羅の一撃」などの専用付与技についている（「クリティカル発生時に大ダメージ」とセット）。

## 4. 効果量（技威力・効果一覧ページ、有志の推定式）

技ランク係数: 基本技（状態異常付与攻撃）＝10、基本技（単体補助・状態異常のみ）＝20、
必殺技 序12 / 改13 / 真14 / 極15（初期必殺技: N≒改、S≒真、H/SP≒極）。
技Lv倍率: Lv1〜10 = 1.00, 1.05, 1.10, 1.15, 1.20, 1.25, 1.30, 1.35, 1.40, 1.50。

| 効果 | 式 | 例 |
|---|---|---|
| 与ダメアップ・被ダメアップ | 100 + 1.5×ランク×Lv倍率×100÷30 (%) | 基本技の付与攻撃 150% / 基本技の単体補助 200% / 序Lv1 160% / 極Lv1 175% |
| 与ダメダウン・被ダメダウン | 100 − 1.2×ランク×Lv倍率×100÷30 (%) | 基本技の付与攻撃 60% / 極Lv1 40% |
| 早める | 1×ランク×Lv倍率×100÷30 (%) | 改Lv1 43.3% |
| 遅らせる | 0.75×ランク×Lv倍率×100÷30 (%) | 基本技の付与攻撃 25% / 改Lv1 32.5% / 極Lv1 37.5% |
| 行動不能 | floor(0.25×ランク×Lv倍率×10)÷20 (秒) | 基本技の付与攻撃 1.25秒 / 改Lv1 1.6秒 / 極Lv1 1.85秒 |

- wiki のコメント: 速100前後だと、遅らせる（32.5%）と行動不能（1.6秒）はほぼ同じ強さ。速100より速い相手には行動不能、遅い相手には遅らせるの方が効く。
- 攻撃＋状態異常の技は、単体攻撃（1.5）より技威力の係数が低い（1.0）。「ダメージを少し削って効果を付ける」作り。
- 全体攻撃の係数は 0.6 で最低。連続攻撃は「1.5÷回数」を回数分なので、合計すると単体とほぼ同じ。
- ダメージ式: ［｛(攻÷防−1)×係数｝+1］×技威力。係数は攻＞防なら0.25、防＞攻なら0.62。

## 5. 万象陣記への落とし込み（この PR での解釈）

- 攻撃方法（8種の SkillKind）はそのまま。**追加効果は別の軸**として、各技に任意の `effect` を1つ付ける（原作の「攻撃＋状態異常／補助」と同じ）。
- 効果量は原作の式をそのまま使う。基本技は付与攻撃ならランク10、ダメージなしならランク20。必殺技はレアリティ（N序12 / S改13 / H真14 / SP極15）× 技Lv倍率。
- 持続は原作どおり「1回で消える」＋上書き（重ねない）。さらに、使われないまま残り続けないように「持ち主が次に1回行動したら期限切れ」を足した。
- 行動不能の秒数は、本作の ATB が原作の約2倍の速さ（速100で2.5秒/周、原作は約5秒）なので 0.5倍 にした。
