## スキル設計ルール（原作寄せ → 実装）

### 最終目標（原作寄り）
- 各カード: **基本技1 + 必殺1**（将来付与枠は任意）
- 行動時抽選: 基本 80% / 必殺 20%（付与ありなら 60/20/20）
- 必殺が反撃・常時のときは行動抽選から外す

### いまの実装への載せ方（段階）
1. **Phase A（今すぐ）**: スキル欄は1つ＝「基本技相当」。表の「基本技」だけデータに入れる。必殺案は表に書いておき後で接続。
2. **Phase B**: `basicSkill` + `specialSkill` を持ち、ATB行動時に 8:2 抽選。
3. **Phase C**: 反撃・常時・付与を追加。

### 範囲ラベル対応（現行 SkillKind）

| テンプレ表記 | kind |
|--------------|------|
| 正面 | front |
| 貫通 | pierce |
| 薙ぎ | sweep |

（将来）縦列・後衛狙い・十字などは kind 追加が必要。

## 命名・世界観

- 陣営の「兵・弟子・使い」で増やすと絵の仮置きがしやすい
- 例: 煌龍 → 鱗兵／鉄騎 → 槍卒／天翔 → 翼士／滅刃 → 影兵／霊獣 → 眷属／幽鬼 → 呪徒
- 名前は和風短名 or 「二つ名・種族名」どちらかに揃える

## パーティコスト上限（現行マップ）

11ノード（本拠 `shrine` + 占領可能10）。`costCapFor(capturedCount)`:

- 開始（本拠のみ count=1）: **10**
- 追加占領ごと **+1**
- 全占領（count=11）で **最大20**: `min(20, 9 + capturedCount)` または `min(20, 10 + max(0, capturedCount - 1))`
